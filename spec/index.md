# Индекс спецификаций сайта документации

Шаблон — обычный Quarto website. Собственной версии расширения у сайта нет;
состояние исходников определяется Git ref. Команда установки находится в
[Taskfile.yml](../Taskfile.yml), фактическая версия каждого установленного
пакета — в его `_extension.yml` под `_extensions`.

| Документ | Статус и область |
| --- | --- |
| [Контракт сопровождения сайта](site.md) | Действующий: native website, готовые демонстрации, source/search и штатный gh-pages |
| [Руководство](../guide/index.qmd) | Авторские действия; нормативные правила у владельцев |
| [Владельцы спецификаций](../guide/specifications.qmd) | Навигация к контрактам установленных инструментов без отдельной матрицы версий |
| [Результат реализации](../docs/releases/2026-10-08-implementation.md) | Исторический отчёт о создании сайта |
| [Карта сохранённой истории](https://github.com/Afonenko-Course-Tools/quarto-template-course/blob/d2376c0e0d555d54ad2ddcfe765af74106a5d596/docs/history/2026-10-08/README.md) | Исторические планы и происхождение решений |

У каждого правила один владелец. Core задаёт общую учебную модель; этот
репозиторий задаёт только сопровождение сайта. README, руководство и примеры
не образуют отдельного общего контракта. Исторические ready-группы сохраняют
свои immutable producer releases и не описывают актуальную установку.
