Одна презентация

Одна презентация подходит для объяснения в аудитории и повторения дома. Presentation оформляет заметки и ответы; Navigation добавляет поиск и переходы Reveal. Core проверяет учебную разметку, если она используется. Обычные слайды ниже не включают банк; банковская политика Core 5.0.2 действует при явном включении банка.

Постоянные выходы к курсу, индексу лекций, исходнику и форме сообщения об ошибке показаны в отдельном исполняемом примере навигации.

Подключите нативные средства

Core, Presentation и Navigation устанавливаются одним выпуском:

quarto add Afonenko-Course-Tools/quarto-course@v5.0.2 --no-prompt

Сохраните _quarto.yml рядом с slides.qmd. Нативные параметры формата задают иерархию заголовков, последовательное движение и CSS; фильтры оформляют материал, а плагин Navigation работает с результатом Reveal:

lang: ru
filters: [course-core, course-presentation]
format:
  revealjs:
    shift-heading-level-by: -1
    slide-level: 2
    navigation-mode: linear
    revealjs-plugins: [course-navigation]
    css: prose.css
    pdf-separate-fragments: false

Выровняйте обычные абзацы

Сохраните prose.css рядом с документом:

/* Обычные абзацы; язык переносов задаёт нативный lang: ru. */
.reveal .slides section p {
  text-align: justify;
  text-align-last: left;
  hyphens: auto;
}

/* Заголовки, код и вывод сохраняют левое выравнивание. */
.reveal .slides section :is(h1, h2, h3, h4, h5, h6, pre, code),
.reveal .slides section .cell-output p {
  text-align: left;
  text-align-last: auto;
  hyphens: none;
}

/* Изображения и их подписи не являются обычными абзацами. */
.reveal .slides section figure p {
  text-align: center;
  text-align-last: auto;
  hyphens: none;
}

Обычные абзацы выравниваются по ширине; последняя строка остаётся слева. Заголовки, код и вывод выравниваются слева. CSS сохраняет размеры шрифта и подсветку. lang: ru задаёт язык для hyphens: auto; фактические переносы зависят от словаря браузера. Это штатное подключение CSS Quarto, без нового параметра course-presentation.

Начните раздел с материала

В slides.qmd YAML title задаёт название лекции, ## — раздел, ### — слайд. shift-heading-level-by: -1 и slide-level: 2 применяются только к Reveal; при выборе HTML уровни остаются исходными.

Раздел может начинаться с объяснения сразу после ##. Пустая заставка раздела получается, когда автор сам оставляет заголовок без вводного содержимого перед первым ###. Граница --- создаёт безымянное продолжение; Navigation сохраняет его в группе текущего раздела. Повторное название ### продолжает тему, а следующий ## начинает новую группу даже при таком же названии. Для устойчивых ссылок задавайте разные ID.

Полный исходник ниже показывает два раздела с материалом, повторные названия и два безымянных продолжения:

---
title: От вопроса к объяснению
---

## Наблюдение {#sec-observation}

Наблюдение помогает сформулировать вопрос и выбрать способ проверки объяснения.
Раздел сразу содержит материал; отдельная пустая заставка для него не нужна.

### Изменение состояния {#state-before}

Сравните значение до выполнения операции и после неё. Сначала предскажите
результат, затем проверьте, какая часть состояния изменилась.

```text
значение до: 3
операция: прибавить 2
```

---

Продолжение того же объяснения не требует нового заголовка. Физическая граница
слайда помогает сохранить читаемый объём текста.

### Изменение состояния {#state-after}

Повторное название сохраняет тему сравнения. Идентификаторы двух слайдов
различаются, поэтому ссылки ведут к нужной части объяснения.

::: {.cell-output .cell-output-stdout}
```text
значение после: 5
```

Результат: значение увеличилось на два.
:::

## Наблюдение {#sec-generalization}

Одинаковое название нового раздела не объединяет его с предыдущим: границу
задаёт заголовок раздела. Здесь обобщаем связь между операцией и изменением
состояния.

---

Продолжение второго раздела остаётся в его группе навигации.

Тот же исходник, CSS и конфигурация двух форматов находятся в примере владельца bundle 5.0.2. quarto add устанавливает расширения; три исходных файла примера копируются из указанного Git ref отдельно. Установка не создаёт папку примеров в курсе.

Покажите ответы и общие заметки

При обычном открытии общие .notes видны рядом со слайдами, ответы свёрнуты. Кнопка «Аудитория» скрывает заметки и сохраняет открытые ответы. Кнопка «Изучение» возвращает их. Режим действует до перезагрузки; явная ссылка slides.html?course-mode=lecture открывает аудиторный режим.

Этот фрагмент можно добавить в выбранный раздел после его вводного материала:

### Прогноз {#slide-predict}

::: {#exr-predict}
Предскажите результат.
:::

::: {#sol-predict}
Объяснение результата.
:::

::: {.notes}
Общие пояснения, доступные всем читателям.
:::

Показ заметок использует API Reveal showNotes; окно по клавише S остаётся штатным. Поиск включает заметки, подсказки и решения. Прямая ссылка и результат поиска раскрывают только цель и её родителей. При печати ответы открываются, заметки исключаются, длинный слайд продолжается на следующих страницах. После обычной печати экранное состояние восстанавливается.

В обычных слайдах вне банка авторские ответы публичны. Если явно включён банк, student Reveal применяет ту же statement-visibility и правило канонической demonstration, что книга. Решения банка автоматически на отдельные слайды не переносятся. Общие заметки остаются публичными.

Нативные фрагменты и форматы

::: {.fragment}
Этот вывод появляется после очередного перехода Reveal.
:::

Фрагменты, заголовки слайдов, форматы и PDF остаются средствами Quarto. Для статически раскрытых доступных ответов используйте:

course-presentation:
  answers: expanded

HTML оформляет доступное решение штатным сворачиваемым callout; Reveal — details; PDF/Typst/LaTeX сохраняют статическое содержимое. При ?print-pdf открываются ответы, callout, фрагменты и вкладки; notes исключаются. Банковская приватность применяется до оформления и печати.

Соберите слайды

quarto render slides.qmd --to revealjs --fail-if-warnings

Команда создаст slides.html. Откройте его для самостоятельного просмотра или используйте ссылку с ?course-mode=lecture для занятия. Условия, ответы и общие заметки демонстрации намеренно публичны.

Смотрите также готовые презентации и исходные папки каталога. Готовые группы сохраняют собственные исторические выпуски; новый нативный пример выше относится к bundle 5.0.2. Ссылка на QMD слайдов остаётся обычной ссылкой; HTML Code Tools не добавляется к Reveal. Подробнее — в справочнике исходников.
