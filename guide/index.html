Руководство

Начните с результата, который нужен читателю. Страницу, книгу и презентацию создаёт Quarto. Расширения добавляют банк с назначениями, оформление учебных блоков, общий сайт самостоятельных проектов и выбранный экспорт.

Уведомление

Руководство закрепляет Core v4.0.1 и готовые группы из каталога. Версии и спецификации дают точные теги инструментов, демонстраций и владельца каждого правила.

Что вы готовите Что использовать Следующий шаг
Первую страницу, книгу или слайды Нативный Quarto; Presentation по желанию Первый документ
Общий банк задач Core и явный банковский opt-in Модель курса, задачи
Решение для преподавателя или публичный разбор Связь по суффиксу либо вложенная solution Решения
Цели, материалы, критерии и учебные акценты Явные course-role Педагогические роли
Лабораторную, семинар, практическую или контрольную Один QMD работы и списки назначений Работы и время
Поле ответа и ключ проверки Ответ Core и возможности адаптера Ответы
Открытый и полный сайт Профили Quarto и политика условия банка Student и full
Одни слайды для аудитории и изучения Presentation и Navigation для Reveal Презентация
Общий сайт нескольких книг и слайдов Publisher; QRC для адресных ссылок Составной сайт
PDF, Moodle XML или поставку PrairieLearn Core и выбранный потребитель Экспорт
Работу в Windows Документированные пути и границы обходного решения Windows

Для обычного документа достаточно Quarto. Для текущей модели нужны Quarto не ниже 1.11.5 и CUE 0.17.1 на путях проверок Core/адаптеров. Java/Gradle требуются для исполнения Java-проекта; они не нужны для просмотра готового HTML. Внешняя LMS и облачная среда проверяются отдельно от локального экспорта.

Каждая страница показывает ситуацию, копируемую разметку и её результат. Каталог дополняет объяснения целыми producer-папками и готовыми результатами. Сопровождение этого сайта описано в README репозитория.
