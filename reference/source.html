Просмотр исходников

Quarto может показать исходник текущего HTML-документа или открыть его в репозитории. Выбирайте способ по тому, где читатель должен изучать документ. Получение целой папки примера и скачивание готового PDF — отдельные действия.

Встроенный исходник

format:
  html:
    code-tools: true
lang: ru

Штатное действие открывает встроенный источник текущего документа. Именно эта настройка используется на сайте руководства. Подписи интерфейса задаёт локаль Quarto; расширения не добавляют собственную кнопку или окно. Для выборочной настройки допустима нативная форма code-tools: {source: true}.

Исходник в репозитории

Для website задайте параметры под website:

website:
  repo-url: https://github.com/organization/course
  repo-branch: main
  repo-subdir: materials
format:
  html:
    code-tools:
      source: repo

repo-branch выбирает ревизию, repo-subdir — каталог проекта внутри репозитория. Для book эти параметры задаются под book. Если исходник расположен по отдельному адресу, source может быть полным URL:

format:
  html:
    code-tools:
      source: https://github.com/organization/course/blob/main/index.qmd

repo-actions: [source] — другой штатный способ перехода к исходнику из боковой области страницы. Если он ведёт туда же, что и Code Tools, выберите один способ, чтобы не показывать два одинаковых перехода. repo-url при этом можно сохранить для остальных ссылок репозитория.

Сопутствующие файлы и форматы

format:
  html:
    code-links:
      - text: Папка примера
        href: https://github.com/organization/course/tree/main/materials

code-links показывает обычные ссылки на связанные файлы. Ссылка на папку нужна, когда пример состоит из нескольких QMD, конфигураций и ресурсов. Открытие source одного документа не скачивает всю эту группу.

HTML Code Tools не обещает такой интерфейс для Reveal или PDF. Для слайдов дайте обычную Markdown-ссылку на QMD или папку группы. Артефакт раздатки свяжите отдельно: [Раздатка](paper.pdf).

Все варианты используют механизмы Quarto. Подробнее — в официальном описании Code Tools и ссылок репозитория.
