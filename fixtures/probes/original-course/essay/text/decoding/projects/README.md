# Проверка проектов

Условия заданий находятся в `../_control.qmd`. Каждый каталог `student/` — самостоятельный стартовый Gradle-проект: после распаковки в нём выполняется `gradle test`. Для выполнения требуется JDK и Gradle, поддерживающий установленную версию JDK. Исходники компилируются с `--release 17`; задания проверены на JDK 25 и JUnit 5.

В полном наборе материалов команда `gradle -p student -Preference -Pgrading test` запускает авторское решение и закрытые проверки. Команда `gradle -p student -Pgrading test` проверяет студентскую версию тем же способом. Эти команды выполняются из каталога конкретного задания.

В `test-design` локальный декодер намеренно ошибочен: корректные тесты должны обнаружить его замену повреждений. Закрытая проверка запускает тесты в отдельных процессах с двумя допустимыми реализациями и двенадцатью ошибочными; успешная проверка требует принять обе допустимые и отклонить все ошибочные. В журнале при этом ожидаемы отказы отдельных тестов ошибочных реализаций, а итоговая Gradle-задача должна завершиться успешно.

В архив для студента входит только содержимое `student/`. Каталоги `reference/` и `tests/`, включая мутационный стенд, остаются в полном комплекте преподавателя. Сгенерированные `build/`, `.gradle/` и файлы `.class` не входят в исходный проект.
