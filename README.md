# Документация инструментов Quarto

[Индекс спецификаций](spec/index.md) различает действующий контракт, согласованную следующую модель и историю. Текущее `main` — **unreleased** сайт документации; версии компонентов и готовых групп закреплены в `Taskfile.yml`.

Обычный Quarto website: последовательное руководство, страницы средств, справочник
и каталог готовых демонстраций. Автор курса начинает с `guide/index.qmd`;
этот README описывает сопровождение самого сайта.
Учебные примеры живут у производителей расширений; здесь их готовые результаты
получаются явно из закреплённых Releases. Основная ветка хранит только исходники
документации; `examples/` и `_site/` исключены из Git.

Требуются Quarto >=1.10.18, Task 3, curl и tar; для получения и проверки — Node.js.
Для установки используйте точные команды `quarto add` из `Taskfile.yml`.

```sh
task install
task fetch
task render
task check
task preview
```

Каждая команда выполняет отдельный этап: `install` устанавливает закреплённый
bundle; `fetch` получает готовые группы; `render` создаёт `_site`; `check`
проверяет ссылки, поиск, навигацию, native source и точное копирование ресурсов;
`preview` открывает локальный просмотр.

После изменения Task-получения выполните `python3 tests/fetch.py`: регрессия
проверяет реальный Task/curl/tar в пути с кириллицей и пробелами и сохранение
прежней группы при отказе получения.

`fetch` скачивает готовый HTML и ресурсы, не запускает языковые среды демонстраций.
`render` и `preview` не выполняют предварительную сборку примеров.
Windows использует PowerShell для операций с каталогами; macOS/Linux — штатные команды.
Локально проверена Linux-ветка; фактическое выполнение на Windows/macOS не подтверждено.

Публикация выполняется вручную, только после проверки: `task publish` вызывает
`quarto publish gh-pages --no-render`. Автоматического deploy workflow нет.
Внедрение от 8 октября включает публикацию после выпуска инструментов, обновления руководства и проверки нового дерева по [плану владельца](docs/plans/2026-10-08-implementation.md).

Структура исходников прежнего учебного шаблона доступна в истории Git и выпуске
`v1.0.0`. Новый авторский контракт описан в руководстве; поддержки старой разметки нет.
