# P0: установленный потребитель и курс из пяти частей

Проба проверяет текущие установленные копии расширений. Основной шаблон курса и его контракт содержимого не заменяются. Нужны Quarto и CUE; TypeScript запускается штатным `quarto run`:

```sh
quarto run tests/probes/installed-consumer.ts --output /tmp/p0-consumer-evidence
# --keep сохраняет временный проект для осмотра.
```

Для каждого запуска создавайте новый каталог результатов. Уже существующие каталоги кеша отклоняются. В отдельный временный проект копируются только исходники примера и файлы расширений. Драйвер отклоняет символические ссылки, каталоги разработки и кеша, встроенные пути к рабочей копии и удалённые импорты TypeScript. Git checkout, node_modules и кеш зависимостей разработчика потребителю не передаются. Эта локальная поставка соответствует минимальной пробе P0; установка по удалённому тегу здесь не проверяется.

## Состав примера

В `fixtures/probes/five-parts` находятся соседние проекты Quarto:

| Владелец | Формат | Содержание |
|---|---|---|
| theory | HTML-книга | Теория и ссылки на лекции и задачи |
| tasks | HTML-книга | Каноническая задача, решение для full, страницы лабораторной и плана |
| practice | Reveal | Ссылки на задачи и теорию |
| lectures | Reveal | Ссылки на теорию и практику, открытые заметки докладчика |
| handbook | HTML-книга | Справочные материалы |
| root | Сайт-портал | Ссылки на все пять частей |

У каждого проекта явно заданы student/full; профиль корня по умолчанию — student. Параметр `home` не установлен: корень сам собирает портал. Все межпроектные ссылки проходят через QRC. Единственное включение, `tasks/_intro.qmd`, принадлежит той же книге задач. Пример использует действующий исходный контракт задач и работ; план представлен обычной авторской страницей. Будущий контракт печати здесь не предполагается реализованным.

Три книги используют штатные `book.repo-url`, `repo-branch`, `repo-subdir` и `repo-actions: [source, issue]`. У Reveal обычные GitHub-ссылки размещены в footer. Адрес репозитория в примере условный: проверяются точные href, запросы на создание issues не отправляются. Имя ветки содержит косую черту, базовый адрес публикации — `https://example.edu/courses/p0/`. Проверяются итоговые пути QRC и HTML-якоря, включая `#/slide-id` у Reveal.

## Что проверяется

- Оба профиля собирают пять частей и портал через документированный интерфейс metadata/finalize. Проверяются семь явных QRC-экспортов, в том числе лабораторная, план и переходы книга ↔ слайды.
- Ссылки source/issue и footer сохраняются после QRC finalize. Для содержимого include действие source ведёт к корневому `tasks/index.qmd`. В HTML и поисковом индексе отсутствуют пути к временному staging.
- При `show-notes: false` заметки остаются в открытом Reveal HTML. Маркеры full отсутствуют в student HTML/поиске и присутствуют в full. В открытых исходниках QMD они остаются намеренно.
- Обычные ресурсы портала и задач публикуются. Один student ZIP и два full ZIP содержат ровно выбранный `README.txt`; соседний справочный каталог исключён. Исходные QMD, Lua, TypeScript и CUE не попадают в проверенный output.
- Неизвестный, конфликтующий и отсутствующий у участника профиль вызывают отказ.
- Ошибка последнего участника, справочника, возникает после успешных предыдущих сборок. Student-портал не публикуется, full-выпуск остаётся прежним. Восстановление использует student по умолчанию и удаляет устаревший файл.
- Сохранён отрицательный случай обычного resources-glob: `tasks/materials/**` переносит `FULL_ONLY_DOWNLOAD` в student. Проба считается выполненной, когда воспроизводит этот известный провал защиты; `results.json` явно оставляет production visibility gate открытым. Отбор ZIP по профилю сам по себе не задаёт политику обычного копирования ресурсов Quarto.

Каталог результатов содержит SHA-256 пакетов и файлов, сведения о происхождении копий, версии инструментов, пути лицензий, журналы, перечни student/full файлов, снимки успешных публикаций и `results.json`. Временный потребитель удаляется, если не указан `--keep`. Результат намеренно проваленной проверки видимости не включается в успешные снимки.

## Локальные зависимости и границы проверки

Каждый render получает новые пустые `XDG_CACHE_HOME` и `DENO_DIR`. Модули скопированных расширений локальны; parse5/entities поставляются внутри QRC. Это проверяет локальность используемых пакетов и независимость от прогретого кеша разработчика. Изоляция всей системы от сети и аудит системных файловых вызовов не доказаны.

В управляемом окружении `strace` завершился ошибкой на `PTRACE_TRACEME`, а `unshare -n` — `Operation not permitted`. Ограничения не обходились.

Переменная `QUARTO_RUN_NO_NETWORK=true` **документирована** в [Quarto Project Scripts](https://quarto.org/docs/projects/scripts.html#quarto-16-breaking-changes). Ранее описание ошибочно называло её недокументированной. Она относится к сетевой загрузке импортов интерпретатора; документация также предупреждает об ограничениях импортов `stdlib/`. Это не универсальная блокировка HTTP и сети дочерних процессов. Текущая проба не использует эту переменную и не подменяет ею проверку локальности поставки.

Исследовательский запуск с `QUARTO_DENO_EXTRA_OPTIONS` приводил к повторению `--v8-flags` при вложенных вызовах; проба его не использует. Внутренний формат кеша `.quarto` и недокументированные API не читаются. Интеграция использует штатные настройки render/profile и интерфейс project-publish.

CUE устанавливается отдельно: расширение содержит схему, но не исполняемый файл. Лицензионная ведомость исходной поставки неполна. В QRC присутствуют лицензии самого расширения и parse5 (MIT), entities (BSD-2-Clause); в скопированных Core, Presentation, Navigation, Download и Publish лицензионные файлы отсутствуют. Манифест фиксирует это, не назначая за авторов новую лицензию.

Проверка HTML и якорей не доказывает интерактивное поведение Speaker View, прокрутку, мобильную навигацию или читаемость браузерной печати. Новая связка Print/PDF → ZIP, нативная Windows и реальные LMS также не входят в эту исходную пробу. Сопровождающие пробы следующих поставок должны отдельно закрыть соответствующие границы.

## Исходное окружение и регрессии

Проверено 1 октября 2026 года: Quarto 1.11.5, Deno 2.7.14, CUE 0.17.1, XeTeX 0.999995 из TeX Live 2023/Debian. Версии скопированных расширений: Core 2.0.0, Presentation 0.1.0, Navigation 0.2.0, QRC 2.0.0, Publish 1.0.0 и Download 1.0.0. В QRC включены parse5 7.3.0 и entities 6.0.1.

Также прошли проверки исходного шаблона:

```sh
quarto run tests/check.ts
quarto run tests/external.ts
quarto run tests/features.ts --course .
```

`check.ts` собрал оба профиля, действующую композицию из пяти участников, реальные XeLaTeX-раздатки и отдельные примеры Cloud/PrairieLearn; проверены 768 локальных ссылок и 129 возможностей. `external.ts` проверил локальный HTTP-импорт, `features.ts --course .` — 129 из 129 демонстрируемых возможностей. Эти результаты сохраняют прежнюю PDF-поставку; они не означают готовность новой политики печати и ресурсов.
